# Installation

Find all packages and installation instructions at [npmjs.com](https://www.npmjs.com/org/nimbus-cqrs).

The packages are published as plain ESM with type declarations and run on Node.js 24+, Bun and Deno.

# Documentation

Find the full documentation at [https://nimbus.overlap.at/](https://nimbus.overlap.at/).

For coding agents and LLM tools, the site also publishes [llms.txt](https://nimbus.overlap.at/llms.txt) (guide index) and [llms-full.txt](https://nimbus.overlap.at/llms-full.txt) (full guide in one file), following the [llms.txt specification](https://llmstxt.org/).

All publicly exported elements are documented with JSDoc comments, so the API reference is available directly in your editor.
